# LOPOE cuộn 3D (bản mẫu, không phải code chạy)
Mở bằng `python3 -m http.server` trong thư mục này. Kịch bản thời gian (p = tiến trình cuộn) ghi ở đầu thẻ `<script type="module">` của `index.html`.
- `window.__p = 0.5` trong console: nhảy thẳng tới một mốc để xem (chỉ dùng kiểm thử).
- `models/ampoule-glb.js`: file `lopoe_ampoule_no_cap.glb` (Drive 00 Inbox/3d render) mã hóa base64 để chạy được trong artifact. Bản thật dùng file .glb trong kho media.
- Sữa rửa mặt và kem đang là ẢNH PHẲNG, hạt thành phần là hình 3D tự dựng: chỉ để chốt bố cục và nhịp. Tài sản thật xem W053.
- Chữ trong bản này là chữ chốt (W054 §Chữ).
