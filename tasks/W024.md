## Việc cần làm (chủ dự án, khoảng 20 phút)
- Vào console.cloud.google.com, tạo project (ví dụ `vive-swipe`), bật thanh toán (Billing). Đặt cảnh báo ngân sách, ví dụ 20 USD/tháng
- Trên Mac: `gcloud auth login` và `gcloud config set project <project-id>` (để Antigravity chạy lệnh thay anh)
- Security → Secret Manager, tạo 2 khóa: `SUPABASE_SERVICE_ROLE_KEY` (lấy ở Supabase → Project Settings → API Keys) và `CRON_SECRET` (chuỗi ngẫu nhiên dài, có thể nhờ Antigravity tạo bằng `openssl rand -hex 32` rồi tự dán). Không dán khóa vào chat
- Cloud Build → Repositories: kết nối GitHub repo `minhduc1395/vive-swipe` (cần đăng nhập GitHub của anh)
- Supabase: bật Anonymous sign-ins (nếu chưa)
- Sau, khi web hoàn chỉnh: gắn tên miền; tạo tài khoản Resend và xác thực tên miền để gửi email

## Tiêu chí xong
- [ ] Có project id, đã bật thanh toán, gcloud trên Mac đăng nhập đúng project
- [ ] 2 khóa có trong Secret Manager; GitHub đã kết nối Cloud Build
- [ ] Ghi project id vào dòng Đầu ra (project id không phải bí mật)
